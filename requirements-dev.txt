# Development and test dependencies for PySimplePMT.
#
# Install alongside the runtime and build dependencies:
#   pip install -r requirements.txt -r requirements-build.txt -r requirements-dev.txt

# Bounded at the next major version, as the runtime and build requirements
# are. requirements.txt says why: a release should be rebuilt and retested
# against a new major rather than silently picking one up.
#
# This file was written without those bounds, and the difference showed up
# immediately. A developer's machine had pytest 8; CI resolved the latest and
# got pytest 9, which deprecates two internals that pytest-bdd 8.1.0 - the
# newest there is - still calls, so every CI run prints PytestRemovedIn10
# warnings that no local run does. They are warnings today and the scenarios
# pass; pytest 10 is where they stop being warnings, and an unbounded
# requirement is one that would pick that up on the morning it is published,
# in the middle of building a release.
pytest>=8.0,<10.0
pytest-bdd>=7.0,<9.0
